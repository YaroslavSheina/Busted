# Идеи: чего не хватает игре и куда расти — бэклог (2026-09-17)

Ответ на вопрос «чего не хватает, какие усложнения и разнообразие добавить, как сделать город интереснее».
Здесь только то, чего ещё нет ни в `mechanics.md` (M1–M10), ни в `career.md` (концептуальные уровни §4).
Ни один пункт не трогает формулу физики: всё — данные уровня, состояние трафика и копа, отрисовка.
Пометки: **рендер** — только рисование, харнесс идентичен; **данные** — поля JSON и состояние; **спрайт** — нужен арт.

Статусы как в `mechanics.md`: `идея` → `в работе` → `на полигоне` → `принята` / `отклонена`. Всё ниже — `идея`.

---

## 1. Чего не хватает игре в целом

- **Причины возвращаться после кампании.** Звёзды и слава есть, но слава ни на что не тратится, после финала делать нечего.
  Нужны бесконечный режим, заезд дня и цель для славы.
- **Бесконечный «Перегон».** Дорога строится на лету из тех же кварталов и событий, плотность и темп растут, рекорд по
  дистанции и очкам. Генератор (`tools/district.cjs`) умеет всё нужное — перенести его из node в игру. Главный режим
  удержания и кандидат для витрины стора. *данные*
- **Повтор и призрак.** Физика детерминирована: запись заезда = seed + лог нажатий с временем. Отсюда бесплатно —
  повтор момента BUSTED, призрак лучшего заезда на трассе, код заезда, которым можно поделиться, заезд дня с общим seed
  для всех игроков. *данные*
- **Слава как валюта.** Краска машины уже есть (`tint`); добавить наклейки, номера, цвет мигалки за сбитых копов.
  Только косметика, силу не покупаем. *данные + рендер*
- **Персонажи.** Диспетчер, который даёт заказы и комментирует по рации (строки в карточках), и один именной коп,
  который возвращается в каждом районе злее. *данные + спрайт копа*
- **Музыка** и её нарастание по близости копа. Единственный большой пробел в звуке (`audio.ts`).

## 2. Разнообразие уровней и целей

Сейчас цель одна: доехать от A до B. Другие цели меняют игру сильнее любого препятствия.

- **Оторваться.** Гаража нет, победа — коп отстал на N секунд. Финал района как «выжить 40 с», в конце копа
  отрезает поезд или разводной мост. *данные: тип цели уровня*
- **Перехват.** Роль наоборот: впереди едет цель, она перестраивается, надо догнать и подрезать. Почти то же, что
  заезд на рампу, только без прыжка. *данные*
- **Три адреса.** Маршрут с двумя промежуточными воротами, через которые надо проехать, а не мимо. Ошибка полосы у
  ворот стоит круга. *данные*
- **Против шерсти.** Односторонняя улица навстречу: все полосы встречные (`oncoming: 3`). *данные, одно число*
- **Тёмный квартал.** Свет отключён, видно только конус фар и габариты машин. Ручка «информация» из `career.md` ещё
  не использована. *рендер*
- **Хрупкий груз.** Впритирку не даёт очки, а отнимает. Уровень, где привычка к Near Miss наказывается. *данные*
- **Модификаторы для повторов.** Зеркало (x → −x всех данных), туман, без HUD, другая машина. Каждый пройденный
  уровень получает три версии почти бесплатно. *данные*

## 3. Город интереснее

Сейчас все кварталы — здания, район отличается палитрой. Различать районы должны геометрия и то, что между дорогами.

- **Типы кварталов.** Парк, парковка, стройка, рынок, пустырь, депо. Для стройки и депо спрайты уже есть: погрузчики,
  коробки, конусы, контейнеры (`public/art/pixel`). *рендер*
- **Ориентиры.** Мост над рекой с водой по бокам (вылет — «в реку»), эстакада, под которой проезжаешь, порт с кранами,
  стадион с пробкой вокруг, железнодорожный парк. Один ориентир на район, вокруг него — фирменный уровень.
  *рендер + спрайты*
- **Не только сетка.** Диагональный проспект, S-образная набережная вдоль реки, кольцо. Дуги движок умеет, генератору
  нужны новые шаблоны. *генератор*
- **Жизнь без столкновений.** Машины на боковых улицах и во дворах, пешеходы на тротуарах, пар из люков, мигающие
  вывески, мерцающий фонарь. Всё в рендере, без физики. *рендер + спрайты пешеходов*
- **Город растёт на карте.** Открытый район появляется на карте (`map.ts`) со своими ориентирами, закрытый стоит в тумане.
  *рендер*

## 4. Преграды

Все нынешние преграды статичные: увидел, решил, проехал. Следующий шаг — преграды, которые меняются, пока едешь.

- **Пост, который смыкается.** Полицейские машины выезжают поперёк на глазах, просвет сужается по времени. *данные*
- **Машина выезжает с парковки.** Стоящая машина в правой полосе трогается задним ходом, когда игрок за N px
  (триггеры по дистанции уже есть: `reds`, `slow`, `rails.before`). *данные*
- **Маршрутка.** Автобус в правой полосе останавливается каждый квартал и трогается: полоса то живая, то мёртвая. *данные*
- **Мусоровоз.** Едет медленно, останавливается у баков (спрайт бака есть). *данные + спрайт*
- **Разводной мост.** Пролёт поднимается по таймеру: успеть, прыгнуть с рампы, а ждать нельзя — тормозов нет.
  *данные + рендер*
- **Масляное пятно и лёд.** Участок с низким сцеплением и сносом, как ежи, но выживаемый; читается по блеску асфальта.
  *данные (число grip по зоне) + рендер*
- **Лежачий полицейский.** Короткий подскок без руля на четверть секунды: мини-рампа без прыжка. *данные*
- **Нерегулируемый перекрёсток.** Поперечные идут без светофора, читать только по машинам. *данные*
- **Трамвай.** Рельсы вдоль дороги, длинный вагон в средней полосе, никого не объезжает. *данные + спрайт*
- **Шоссе.** Четыре-пять полос, быстрый трафик, съезды, с которых вливаются машины. Нужно расширить `lanesFor`. *данные*

## 5. Погони

Коп сейчас один тип: сзади, быстрее или медленнее. Разнообразие погони важнее разнообразия постов: коп — единственный
противник, который реагирует на игрока.

- **Засада с боковой улицы.** Коп подключается на перекрёстке, а не со старта. *данные*
- **Лобовой.** Коп во встречной полосе идёт на таран, надо разминуться. *данные*
- **Ежи от копа.** Пост появляется впереди по триггеру, когда коп близко. *данные*
- **Вертолёт.** Прожектор ходит по дороге, в луче коп ускоряется. *рендер + одно число + спрайт*
- **Характеры.** «Бульдог» — медленный и не отстаёт никогда; «Гончая» — быстрая, но широко входит в углы, её теряют
  в тесноте; «Двойка» — боксируют с двух сторон. *данные копа*
- **Уровень розыска.** Каждый задетый трафик поднимает звезду, коп получает скорость; чистая езда снимает.
  Риск-менеджмент внутри заезда. *данные*
- **Босс-погоня.** Именной коп в конце района с тремя фазами, без гаража, снять только сценарным событием. *данные + спрайт*

## 6. Порядок, если брать

1. Типы кварталов и ориентиры — только рендер, спрайты частично есть, район сразу узнаваем.
2. Динамические преграды: смыкающийся пост, выезд с парковки, маршрутка — данные и состояние трафика.
3. Погоня: засада, характеры, правило «оторвался» — отсюда новый тип уровня без гаража.
4. Запись заезда, призрак, код заезда — дёшево из-за детерминизма, даёт заезд дня.
5. Бесконечный «Перегон» с генератором в игре.
6. Трата славы на косметику.

Спрайты нужны только трамваю, вертолёту, пешеходам и ориентирам. Остальное собирается из того, что уже лежит в
`public/art/pixel`.
