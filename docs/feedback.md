# Что добавлено и ждёт фидбека с телефона

Список ведётся с 2026-09-14 по договорённости: всё собирается подряд, тест — потом. Каждый пункт: что смотреть и где.
Отмечать: ✅ ок · ✏️ правки (что именно) · ❌ переделать.

## Звук (2026-09-14)
- [ ] Мотор: три голоса с перегрузкой, шум выхлопа, пульсация, дрожание тона. Вопрос: всё ещё «синтезатор»? В какую сторону: глуше, ниже, тише, ровнее. Запасной путь — семпл двигателя.
- [ ] Сирена: громче с близостью копа. Не раздражает ли на длинных погонях (Тоннель, Ночной город · 3).
- [ ] Эффекты: свист впритирку, удар, поезд, звон очков, отсчёт 3-2-1, карточка. Что лишнее, что не слышно.
- [ ] Громкость общая (`?mute=1` выключает).

## Карьера v1 (2026-09-13) — `docs/career.md`, `progression.md` «Карьера v1»
- [ ] Окраина 1–3 (минивэн): темп 28–34 с, посты и ремонт, светофоры зелёные.
- [ ] Центр 1–3 (бывший Район 2, седан).
- [ ] Промзона 1–3 (масл-кар 330): не слишком ли тяжёл в перестроениях; рампа+пост на 1, коп со 2-го, два копа на 3-м.
- [ ] Ночной город 1–3 (спорт 350): трафик 0.4 при встречке — не пробка ли у постов; до трёх копов на 3-м.
- [ ] Финал: 50 с, три копа, без контрольных точек — по силам ли за 3–5 попыток.
- [ ] Порядок машин: седан → масл-кар → спорт — чувствуется ли рост.

## Концептуальные уровни (2026-09-13) — `progression.md` «Концептуальные уровни»
- [ ] Окраина · Стройка: шесть ремонтов, хватает ли места на перестроение минивэна.
- [ ] Окраина · Колонна: пары грузовиков без случайного трафика — читается ли идея.
- [ ] Центр · Красная волна: ритм красных, первый перекрёсток зелёный (сценарий не успевает).
- [ ] Центр · Пробка: плотность 1.5, все на 35–45 % — проходима ли вообще (бот не проверяет).
- [ ] Промзона · Серпантин: характер масл-кара без трафика.
- [ ] Промзона · Товарняк: длинные составы перед носом и за спиной.
- [ ] Промзона · Автовозы: четыре рампы подряд — стоящий автовоз как цель.
- [ ] Ночной город · Тоннель: две полосы шесть кварталов, коп 1.02 — держится ли напряжение, снимает ли его поезд в конце.
- [ ] Ночной город · Дождь: заметна ли разница сцепления 0.7.

## Отклик на события (2026-09-14) — `mechanics.md` «Отклик на события»
- [ ] BUSTED от удара: взрыв, дым, тряска 14 px, машина разбита. Сила тряски и длина взрыва (1 с).
- [ ] Вылет/ежи: только пыль и тряска 5 — достаточно ли.
- [ ] Коп выбыл: взрыв, слоу-мо 0.45 с — не мешает ли рядом с поездом или постом.
- [ ] Приземление после рампы: пыль из-под бортов.
- [ ] Штамп BUSTED/DELIVERED с отскоком.
- [ ] DELIVERED по строчкам каждые 0.45 с со звуком — темп.

## Карта карьеры и HUD (2026-09-14)
- [ ] Карта после загрузочного экрана: районы, машина района, уровни со статусом, «Продолжить». Кнопка ☰ во время игры — на карту (пауза).
- [ ] Пройденные уровни открываются повторно, закрытые — нет. Лучший результат в строке уровня.
- [ ] HUD: полоса маршрута с меткой машины и гаражом, очки крупно, шкала копа (мигает красно-синим), надпись события. Отладочный HUD с ω — только `?debug=1`.
- [ ] После последнего уровня — карта.

## Цели и гараж (2026-09-14)
- [ ] Три звезды на уровень: доставил, без аварий за заход, очки не ниже цели (1.5 «чистых» проезда, округлено до сотен). Достижима ли цель по очкам без гонки за near miss.
- [ ] DELIVERED показывает ★/☆ по целям перед славой.
- [ ] Гараж на карте: пять машин по ярусам, закрытые серые с районом, где откроются. Сумма звёзд вверху.

## История и палитры районов (2026-09-14)
- [ ] Строка истории в интро первого маршрута района: Окраина, Центр, Промзона, Ночной город, Финал. Не длинно ли для карточки перед отсчётом.
- [ ] Титры после финала: экран «ГАРАЖ» на ключевом арте, слава, тап — на карту.
- [ ] Палитры: Обучение и Окраина днём (`pixel`), Промзона на закате (`pixeldusk`, тёплая коричневая), Пролог, Центр, Ночной город, Финал ночью. Читаемость дороги днём и на закате. Твои спрайты сред (пустыня, джунгли) лягут сюда же как темы.
- [ ] Переключатель звука на карте (запоминается).

## Интерфейс, шаг 1 (2026-09-14) — `docs/ui.md`
- [ ] Пиксельный шрифт Press Start 2P в заголовках, отсчёте, очках, кнопках: читается ли на телефоне (он широкий, размеры уменьшены).
- [ ] Временные пиксельные иконки на карте (звёзды, корона, замок, флаг, стрелка, звук): узнаваемы ли, какие заменить в первую очередь.

## Интерфейс, шаг 2 (2026-09-14) — экраны результата
- [ ] BUSTED: причина с иконкой, очки и лучший, подсказка по причине — помогает ли подсказка, не мешает ли панель смотреть на взрыв.
- [ ] DELIVERED: звёзды по одной со звуком, тик очков, полоса славы, штамп «новый рекорд», строка «открыто». Темп ~1.2 с до кнопки.
- [ ] Кнопки «ещё раз»/«дальше» — тап по любому месту экрана работает так же.

## Интерфейс, шаг 3 (2026-09-15) — карта как город
- [ ] Карта: дорога через районы своими палитрами, таблички, точки уровней, карточка внизу. Читается ли прогресс, удобно ли тапать точки (44 px), не тяжёлый ли холст на телефоне (рисуется один раз при открытии).
- [ ] Прокрутка к текущему уровню при открытии.

## Интерфейс, шаг 4 (2026-09-15) — карточка района, гараж, пауза, настройки
- [ ] Карточка района перед первым маршрутом: табличка, машина въезжает, полоски, история. Не лишняя ли перед интро уровня (два экрана подряд).
- [ ] Гараж: полоски характеристик, закрытые машины, выбор машины для повторов — понятно ли, что кампания едет на своей.
- [ ] Пауза по кнопке в заезде: пять пунктов; «заново» — с начала уровня.
- [ ] Настройки: звук, вибрация (на телефоне при BUSTED), сброс прогресса двумя тапами.

## Интерфейс, шаг 5 (2026-09-15) — онбординг, титры, метки на полосе
- [ ] Руки над LEFT/RIGHT на первом заезде пролога: понятно ли без текста, гаснут ли после нажатий.
- [ ] Метки событий на полосе маршрута: помогают ли готовиться заранее или засоряют HUD (10 px иконки над полосой).
- [ ] Титры: чистый кадр арта полторы секунды, потом текст.
