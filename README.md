# BUSTED

Мобильная аркада про угонщика: две кнопки, машина без тормозов, доставить в гараж и не попасться.
Vite + TypeScript + Canvas 2D, без фреймворков. Правила проекта, структура и решения — в `CLAUDE.md`
(его же читает Claude Code), диздок — `docs/concept.md` и `docs/design.md`.

## Запуск

Нужен Node 20+ (разработка идёт на 24).

```bash
npm install
npm run dev
```

Vite поднимает сервер на `http://localhost:5173` и на адресе машины в локальной сети (флаг `--host` уже в скрипте):
телефон в той же Wi-Fi-сети открывает игру по этому адресу. Редактор уровней — `/editor/`.

Сборка: `npm run build` (сначала `tsc --noEmit`, потом `vite build` в `dist/`). GitHub проверяет каждый пуш и pull request
(`.github/workflows/ci.yml`: типы и харнесс ниже); пуш в `main` после зелёной проверки собирается и выкладывается на
GitHub Pages — постоянная ссылка для теста на телефоне без туннелей. Красная проверка — выкладки нет, тестеры остаются
на прошлой рабочей сборке.

## Флаги в адресе

| флаг | что делает |
|---|---|
| `?level=ключ` | сразу уровень, минуя карту (ключ — имя файла в `levels/` без `.json`) |
| `?debug=1` | отладочный HUD (скорость, ω) и меню «авто» / «уровень» |
| `?theme=имя` | палитра: `pixelnight` (основная), `pixel` (день), `pixeldusk`, `night`, `comic`, … |
| `?mute=1` | без звука |

Прогресс хранится в `localStorage` (`lr.*`), сброс — в настройках двумя тапами.

## Харнесс

Формула физики (`src/physics.ts`, `step()`) не меняется: игра должна ощущаться как прототип `docs/prototype.html`.
Это проверяется покадрово:

```bash
npm run harness
```

Собирает игру без минификации, склеивает в `tools/harness/port.mjs` с хуком `__lr`, гоняет `tools/harness/compare.mjs`
против прототипа на стабе DOM («порт идентичен прототипу»), затем `tools/harness/sweep.mjs` — ботов по всей кампании
(«все уровни кампании проходимы»). Боты едут без трафика по планам полос из `tools/harness/plans.json`: новый уровень
кампании без плана едет по средней полосе, и если там пост или ремонт — прогон упадёт, пока план не добавлен. Окна
в трафике у постов бот не ловит — это проверка телефоном. Перед пушем после правок игры или уровней — обязательно
(GitHub всё равно проверит и не выложит сломанное).

Один уровень ботом — после `npm run harness:build`:

```bash
LEVEL="Пролог" CLEAN=1 node tools/harness/routebot.mjs
```

Переменные: `LEVEL` — имя уровня как в меню, `LANE` — полоса 0..2, `PLAN` — план перестроений `s:полоса,…`,
`CLEAN=1` — без трафика, `KEEPCOP`/`KEEPRAMP` — оставить копа/автовозы, `OVERTAKE` — обгоны, `LOOK` — прицел (220 для
длинных уровней), `TRACE=кадр` — покадровый лог. Трафик у постов бот не проверяет — только телефон.

## Тестирование на телефоне

Ссылка для тестеров — https://yaroslavsheina.github.io/Busted/ (обновляется после каждого пуша в `main` с зелёной проверкой).
Номер сборки — в правом нижнем углу загрузочного экрана и внизу настроек.

- **Установить.** iPhone: Safari → «Поделиться» → «На экран Домой». Android: Chrome → меню → «Установить приложение»
  или «Добавить на главный экран». С экрана «Домой» игра открывается на весь экран, без панелей браузера.
- **Заметка.** Пауза → «заметка» или кнопка «заметка» на экране BUSTED: уровень, попытка, место и сборка подставляются
  сами, пишешь только «что не так». Сохраняется в журнал; «сохранить и отправить» — ещё и сразу текстом.
- **Журнал.** Игра сама записывает каждую попытку: где разбился и почему, сколько попыток, частота кадров, телефон.
  Настройки → «журнал теста · отправить» — файл уходит в мессенджер через меню «Поделиться».
- **Режим тестера.** Пять тапов по номеру сборки в настройках или ссылка с `?tester=1` — все уровни на карте открыты.
  Прогресс кампании от забегов вперёд не сдвигается.
- **Разбор журналов.** Редактор (`/editor/`) → уровень → «Журнал теста +», можно несколько файлов сразу: аварии красными
  пятнами поверх уровня, брошенные попытки серыми, заметки жёлтыми, под кнопкой сводка по уровню.

## Как работаем

- `main` всегда рабочий. Задача — в своей ветке, слияние через pull request, перед началом `git pull`.
- Один коммит — одно изменение, сообщение по-русски.
- Уровни собирает генератор `node tools/district.cjs` из спецификаций внутри него; JSON в `levels/` руками не правим,
  кроме полигонов механик. Уровни правит один человек за раз — это единственное место, где конфликты вероятны.
- Что сделано и ждёт теста на телефоне — `docs/feedback.md`; идеи — `docs/ideas.md`; механики — `docs/mechanics.md`.
